# Self-Improving Proactive Agent

> [!NOTE] 雾刃自动化渗透测试平台技能库 (WuRen Skill Base)
> 类别: 自动化渗透测试专属技能包
> 用途: 扩展 AI 智能体的实战能力与外部工具调用规范。

## 描述
Sself-improving-agent / Proactive Agent。让 AI 具备主动学习和自我进化的能力，能够在后台自动分析历史任务并优化未来的执行策略。

## 对雾刃平台的适用性
高度契合平台 AI 的“自学习”架构。可用于优化 `learning.py` 中的 RAG 索引构建策略，让平台 AI 在每次渗透测试后自动总结经验教训。
